납부일자 변경 예시

  • 약정일 매월 24일을 매월 30일로 변경하는 경우
      • 7월 23일에 변경요청 시 이전 납부일자는 6월 24일이므로 차회납입일은 7월 30일이 됩니다.
      • 7월 27일에 이전 납부일자는 7월 24일이므로 차회납입일은 8월 30일이 됩니다.
  • 약정일 매월 24일을 매월 10일로 변경하는 경우
      • 7월 23일에 변경요청 시 이전 납부일자는 6월 24일이므로 차회납입일은 8월 10일이 됩니다.
      • 7월 27일에 이전 납부일자는 7월 24일이므로 차회납입일은 9월 10일이 됩니다.
  • 납부일자를 변경하기 전 안내 내용을 확인해주세요.
  • 디딤돌대출: 연 1회에 한하여 변경이 가능합니다.
  • 보금자리론: 연 3회에 한하여 변경이 가능하며, 추가 변경 희망 시 관할 지점으로 문의바랍니다.
  • 단, 현재 연체 중이거나 신청일이 약정납입일 당일인 경우에는 변경이 불가합니다.
  • 원금상환유예중에 납부일자 변경 시 원금상환유예가 종료됩니다.
  • 변경 후 첫납부일자는 이전 납부일자로부터 1개월 후 최초로 도래하는 납입일자입니다. (매월 약정납입금이 변경될 수 있으니, 반드시 확인하시고 신청바랍니다.)
  • 납부일자 변경 시 마지막 회차 납부일(만기시점)은 변경 상환예정일자>만기일자인 경우 만기일자로 적용됩니다. (대출만기일자는 최초 대출 실행 시 이미 확정된 것으로 납부일자를 변경하더라도 만기일자는 변경되지 않습니다.)
